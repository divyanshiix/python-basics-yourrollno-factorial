# Factorial Calculator

A simple Python program that calculates the factorial of a non-negative number entered by the user.

## Features

- Accepts a number from the user
- Calculates the factorial using a `for` loop
- Displays the calculated factorial
- Handles negative-number input with a helpful message

## Installation

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open a terminal in the project folder.

## Requirements

- Python 3

## Usage

Run the program with:

```bash
python factorial.py
```

Enter a non-negative number when prompted.

## Example

```text
Enter a non-negative number: 5
Factorial of 5 is 120
```
